# Original TrollSpeed

DarkSpeed is based on the original [TrollSpeed](https://github.com/Lessica/TrollSpeed) project by i_82 / Lessica.

TrollSpeed supplied the original network-speed collection, settings, positioning, and presentation design that DarkSpeed adapts for its signed IPA and SpringBoard renderer. The upstream Git history is preserved in this repository so authorship remains visible.

For TrollSpeed's original documentation, source, releases, and contributor list, visit the [upstream repository](https://github.com/Lessica/TrollSpeed).

DarkSpeed's build and installation instructions are maintained in [README.md](README.md) and [README_ZH.md](README_ZH.md).
